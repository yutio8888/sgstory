## 体验与取舍

- 本篇以观察解谜为核心，保留三种预设及专家车卡，但属性不锁定剧情；不随机丢失关键线索，不增加资源条、职业或战斗系统。
- 原作没有规定这里的数字游戏路线、送餐逻辑、无限施符、信任旗标或三个结局；它们是本次改编。过去的学者/厨师警报追逐简化成固定守卫阻挡，避免没有主持人裁定的追逐死锁。
- 杖跨时代移动时保持楼层，物品与手记随玩家保留；不模拟所有历史因果。过去答应幼龙后，信任作为个人旅程记录用于成年龙对话。
- 和平：养龙书＋幼龙承诺＋浮空符文或护符；优先用符文，否则耗护符一次。保留原作三次刻痕，但当前章节只有一次可消耗的和平结局行动，其余次数留在结局清单中。
- 取宝：盾优先，否则消耗防火卷轴一次。巨剑是原作遗物，目前没有独立战斗用途。金币作为叙事结局，不改森林角色的金币经济。
- 手记、探索地图与提示使用可折叠面板，打开不生成行动；地图只列已到过的房间名称。风险与结局条件在操作前显示。
- 同一份动作列表同时控制链接与结算许可。非法操作返回原状态，遗物与知识不可重复领取，结局后不再提供会结算的行动。

## 兼容与运行

这是独立克隆的 sgstory，不是《幽冥倒悬》的内容包。仓库不含后者的 PROGRESS、冻结宪法或 ADR，故沿用本仓库 npm、Twee、SugarCube 与测试链。未修改父目录项目。

原 Story IFID、标题、森林段落和变量保持兼容；旧存档没有 `$adventure` 时仍显示森林角色卡出口。本篇仅在新入口后初始化 `$tower`，完整状态进入 SugarCube 存档/历史。已有旧版本的实际用户存档文件未提供，故没有声称完成历史文件迁移验收。

```sh
npm ci
# 字体构建依赖；建议安装在 Python 虚拟环境中
python3 -m pip install fonttools brotli
npm test
npm run serve
```

如果 npm 12 环境以 `allow-remote=none` 拒绝锁文件中镜像 tarball，可在确认这些锁定依赖后仅为本次命令指定 `npm ci --allow-remote=all`。不必修改全局配置或锁文件。
