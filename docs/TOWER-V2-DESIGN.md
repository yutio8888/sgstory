# 诺斯塔之塔 v2 · 规则与交互合同

本次将 v1 的读书后直接展示出口，改为可回溯的三幕解谜。保留十一层、过去／现在、时光杖、养龙书、浮空符文、巨剑、护符、防火卷轴和盾。抄写员、出征账册的伪令、驯龙铜铃、排烟闸与具体因果属于本改编新增内容，并非原作既有规则。来源和许可见 NOUSTA.md；塔篇内容继续 CC BY-SA 4.0。

## 剧本骨架

第一幕让玩家发现龙被当作兵器：养龙书提供倾听方法，寝室提供梁的支点和伪造账册。抵达塔冠过去，幼龙要求自己选择去处。玩家能先探索任何楼层，也能先准备机关，不按固定任务顺序锁门。

第二幕为可操作的准备：为飞离塔顶开出口、排烟、拆去以声音控制龙的铜铃。另有救抄写员、以核验暗记揭穿伪造袭村令的证据链；这条支线开启另一种终局。跨时代改变只应用于明确标记的局部机关与命令，人物不会自动随玩家穿越。

第三幕回到现在的塔冠选择：邀请龙飞走，或者在撤令和证人支持下让它自愿留下修建避难所。也可用防火道具取宝离开，或随时退回塔门结束调查。

## 有限道具与替代路线

| 目标 | 护符方式（各耗一次） | 不用护符的困难方式 |
| --- | --- | --- |
| 救第七层现在的抄写员 | 托起坠井吊架 | 第三层学符文，第六层现在取绳，再到井口先下井系绳再救人，绳留在井口 |
| 打开第八层现在的排烟闸 | 托起整扇重闸，卡进止回槽 | 第五层现在拿烟罩长刷，第八层过去清槽，再回现在转检修轮 |
| 开第十一层现在的出口 | 托起重梁，固定到外墙 | 第四层读结构图，用第七层遗物巨剑楔住支点，再执行扳梁；巨剑留在梁下 |

护符还有第四个可选用途：在第九层现在抬起沉重铁床架，取回罹难者名册。名册没有免费替代取得方式，也不影响任何结局的条件；带出塔后可以逐一报信，给无名遗骸留下归乡的去处。

护符起始三次，仅从遗物领取一次，不可补充。四个用途均不结束游戏，总次数无法包办四处：若救人、排烟、开顶与回收名册都要完成，至少一处必须采用人工替代路线。名册可以错过，但主线始终有补救办法；全部次数耗尽后仍可完成任一已满足条件的结局。浮空符文只能托起一个人一分钟，不能搬动闸门与屋梁，因此不能全面替代护符。没有随机检定、属性门槛、新资源条或倒计时。

第十层过去拆铃、塔顶取宝需要挡火。优先用不消耗的防火盾，否则消耗一次性卷轴。盾可从第九层过去取得，因而卷轴用尽仍有永久替代；所有火焰行动在标签的 cost/hint 中预告具体消耗。拒绝不存在或条件不足的行动不会改变对象、记录、道具或次数。

## 四个终局

| ID | 条件 | 后果 |
| --- | --- | --- |
| free | promise、exitOpen、vented、bellSilent | 龙自行飞走；玩家不取金币 |
| pact | promise、decree、witness、bellSilent | 撤销袭村令后龙自愿留下，将财宝用于避难所；不要求开顶排烟 |
| treasure | shield 或 scroll | 玩家独自取宝离开；卷轴无盾时烧尽；正文承认此前是否已经开顶 |
| leave | 返回第一层 | 结束本次调查，去处悬而未决 |

终局条件在动作出现前可查看。终局动作标注“结束冒险”，结算后 actions 为空。铃、排烟、开顶与撤令互不撤销，因此可试探、回访、补线索；所有非终局状态始终允许切换时代，二层以上始终可下楼。过去第六层守卫可送餐或浮空取得永久通行，也可到现在绕行；过去第十层始终不许上楼，但可在现在上楼后切换到过去见幼龙。

## 稳定 API

- `setup.newTower()`：新建纯数据 `version:2` 状态。
- `setup.towerActions(s)`：纯查询，返回 `{id,label,kind,hint,cost}[]`。`kind` 为 clue/tool/history/ending/travel，hint、cost 可为空字符串。
- `setup.towerAct(s,id)`：合法行动返回新对象及复制后的 notes/visited；非法或重复操作返回原对象。
- `setup.towerObjective(s)`：当前幕的目标字符串。
- `setup.towerBlocked(s)`：当前位置缺失条件的字符串数组。
- `setup.towerInventory(s)`：`{label,detail}[]`。
- `setup.towerEndingTitle(s)`：结局标题字符串。
- `setup.towerRooms`、`setup.towerDescription(s)`：由 49-tower-world.twee 的叙事投影负责。

状态沿用 floor（0–10）、era、visited、notes、book、rune、meal、guards、loot、shield、scroll、charges、promise、ending、message，新增 sketch、sword、rope、ropeTaken、witness、ledger、brush、drainCleared、vented、beamWedged、exitOpen、bellSilent、decree、memorial。新增项均为明确事件旗标，不是可刷数值资源。ropeTaken 与 rope 分别表示是否已领取、是否仍携带，以免使用后重复领取。

## 旧存档

48-tower-legacy.twee 保留 v1 的原始初始状态、动作条件和结算；只重命名为 newTowerLegacy/towerLegacyActions/towerLegacyAct。公开 API 遇到 `version === 1` 原样分派，不迁移、不重置资源，不给旧档引入新结局条件。旧场景与提示使用 towerRoomsLegacy；新建旅程才采用 v2。没有 version 的森林存档不在塔状态迁移范围内。
