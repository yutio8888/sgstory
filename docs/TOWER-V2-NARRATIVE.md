# 诺斯塔之塔 v2：叙事改编

本页记录 v2 新旅程的场景叙事；旧版行为与场景基文保留供 v1 存档使用，回访文字按已有状态补充。实现位于 `src/49-tower-world.twee`，其中 `setup.towerDescription(s)` 只读取状态，不触发行动或写入手记。

## 三幕与人物

第一幕（塔基至寝室）让玩家先理解塔：同一处阶梯可以有两种面貌，喂食表只安排出征，速写只替龙安排用途。养龙书提供倾听的方法；浮空的墨滴让“一分钟之后仍会落下”成为可观察的限制。塔顶结构图把神秘囚笼还原成可以处理的实物。

第二幕（厨房至驯龙层）让观察转成责任。烟道、悬绳、重梁与铃都是具体障碍。护符的使用与其他解法由规则层裁定；正文呈现重量、烟流和声响，按需提示才解释思考方向。抄写员是遗物层新增的单一可选人物：他近期为核对遗迹中的名字而来，坠入破损吊架。获救后，他先展平攥皱的纸，再说自己差一点也成了等待辨认的名字。他提供古账册核验暗记，随后沿楼梯离塔；回访只留下手印与玩家的回忆，订约时由玩家转述暗记与更正印的来历；这条情感结果不以选择某个龙结局为前提，也不需要让人物跨越年代。

第三幕（塔冠及回访）把“长大”与“敢于行动”分开。幼龙先以报复掩饰发抖，得到倾听后才问自己有没有离开的权利。成年龙记得承诺，但仍害怕铃声与抬起的手。顶梁移开、热烟散去、铃声停止，各自改变身体动作；它并不因为一个旗标就突然毫无恐惧。记录与见证者使约定路线能够谈及被袭村庄，而非只讨论龙与玩家。

兵营的现在另有一条可错过的小支线：用一道护符刻痕抬起铁床架，取回罹难者名册。它没有免费替代，不是任何主结局的条件；回报是把姓名完整带出塔。四种护符用途共享三道刻痕，想完成全部可选内容就须在救人、排烟或开梁时使用至少一种其他解法。正文在领取后显示空下的压痕与包好的名册，避免重复描述尚待取得的纸页。

## 动态叙述

- 书、符文和结构图已记录后，描述承接已有知识。
- 已领取的盾、遗物与绳不再作为地上的可取物出现。
- 卫兵已通过、热饭已端走时，正文承认已有进展。
- 救人、疏通排烟槽、拆铃和撤销伪造命令后，回访显示改变留下的痕迹。
- 塔冠按承诺、出口、排烟、静铃与见证条件追加可观察的反应。

场景基础字段保持 `name/past/present/hint`，以兼容地图与提示界面。v1 数组另存为 `setup.towerRoomsLegacy`，避免旧旅程显示没有对应动作的新任务。

## 文案校订（2026-09-10）

在独立 worktree 中审视塔篇全部文案，重点消除描述与状态的矛盾：尚未领取护符与次数耗尽分别提示；切换时代只能绕路上楼，过去当面对证仍需取得通行；浮空只托起一人一分钟，消耗品不会因切换时代恢复。拆铃反馈明确取下整只铜铃，与回访时的空钩一致。账册先呈现疑点，再由救人获得的暗记支持核验。提示入口明确告知会说明解法，场景正文减少直接评价玩法的句子。

本次不改变行动条件、资源消耗、结局条件或存档结构。旧版规则与场景基文保留，回访投影会承认已取走物品、取得通行或许下承诺；已有存档中的历史消息和手记不重写，之后行动与场景显示采用校订文案。任一帮助路线满足条件后，目标显示进入第三幕；订约结局把修缮安排在约定之后，避免暗示开顶、排烟是该路线的前置条件。全游戏审校记录见 [文案审校](COPY-REVIEW-2026-09-10.md)，验证记录及未覆盖范围见 [当前进度](PROGRESS.md)。
